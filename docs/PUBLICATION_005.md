# Kairos build005: reproducible investigation workbench

This local release makes Kairos reviewable from a clean checkout. One entry point launches a website with genuine captures, provisions isolated authenticated services, reproduces a saved repair, runs acceptance or stops owned resources.

```bash
python3 -m scripts.reviewer demo
```

Follow a repository defect through source/context inspection, proposed patch, independent checks and downloadable evidence. Explicit recorded mode includes 48 published records/683 original blobs and disables login/private commands. Live outages never become fabricated saved results.

Fresh acceptance passed 229 backend tests with six explicit skips, eighteen frontend boundary/client/package tests, lint/types/builds, four recorded browser journeys, four actual OIDC journeys, eleven existing fixture browser journeys, five packaging failure checks and 21 non-root container checks. The original model-generated Django patch reproduced against 110 tests with one skip; its rebuilt image difference is disclosed.

Preserved capacity evidence covers 435,270 local requests over 42 minutes, zero unexpected errors and acknowledgement p95 275.19 ms. The newer frozen repair study stays visible at **0/36 verified evaluation repairs**. These are bounded engineering/model observations, not production-scale or broad-repair claims.

Includes reviewer instructions, five-minute demo, claim map, architecture decisions, screenshots, fingerprints and lossless raw measurements. Historical source/evidence remains preserved. Publication excludes credentials, sessions, dependencies, databases and model weights.

Requires Python 3.12 or newer and Node 24/npm. Demo needs no Docker/database/model; fullstack/repair require Docker. No API spend, hardware purchase or public hosting. See [reviewer guide](REVIEWER_005.md) and [delivery report](FINAL_REPORT_005.md).
