# F025 Run 3 (valid dev cases + best-of-n) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Measure the 025 repair loop (with FIND/READ-tests/RUN) on fair, well-specified development cases, with 2 samples per case and a fair selector, and score them in the pinned Docker sandbox.

**Architecture:**
- Cases: SWE-bench Verified ∩ development bucket ∩ django 3.1 (the pinned `kairos-investigation-django:build003` image) ∩ unexposed. Qualify them with the existing `scripts/f024_qualify.py`.
- Chains: built with the existing `scripts/oracle_context024.oracle_regions` on pinned source.
- Run: `scripts/f025_colab.py` gains sample variants. The user runs it on Colab and `scripts/f025_score.py` scores it.
- Fine-tuning (QLoRA) is a separate plan, written after run 3.

**Tech Stack:** Python 3.12, pytest, pyarrow, tarfile, the existing qualify014/f024 helpers, Docker (pinned images), Colab T4 (`unsloth/Qwen2.5-Coder-14B-Instruct-bnb-4bit@ecfc63c0`).

**Spec:** `docs/REPAIR_REDESIGN_025.md`, Addenda 3 and 4.

## Global Constraints

- Development bucket only (`scripts/localization_dev024.bucket(id) == 'development'`). Validation stays frozen; holdout is never fetched.
- A case is excluded if its id appears anywhere under `evidence/`, `docs/`, `cases/` or `~/Desktop/resume` (exposure).
- Reference patches are used only for qualification and oracle-region placement. Gold text never enters a prompt.
- Oracle context is labelled `oracle`; results must not be reported as issue-only repair.
- Package limits: `ENVELOPE_TOKENS = 3539`; `MAX_NEW = 768`; `MAX_CALLS_PER_CHAIN = 6`; `PACKAGE_CALL_CAP` raised from 48 to **60**.
- Sandbox flags unchanged (`--network=none`, read-only, cap-drop, pinned images, `--pull=never`). `RUN` only with `host_checks=True` (Colab).
- No commits without user approval. Replace each Commit step with "stage only" unless approved.
- Frozen evidence (`evidence/localization024`, `evidence/localization025/f025-run1`, `evidence/localization025/f025-run2`) is never modified.

## Review Focus

1. **A candidate whose environment does not match the build003 image** (for example one needing a newer Python). Expected: qualification marks it not qualified and it is dropped, never scored as a repair failure. Test in Task 2's verification.
2. **A gold patch touching more than 4 hunks or a test-only file.** Expected: `oracle_regions` caps at `MAX_REGIONS = 4`. A case whose gold edits fall outside the captured regions is excluded at chain build, not run. Test in Task 3.
3. **Sample 1 identical to sample 0 at call 0.** Expected: different seeds and `do_sample=True` for sample ≥ 1 at call 0. Test in Task 4.
4. **Two samples, one verified and one not.** Expected: `pass_at_2` counts the case, and `fair_pick` uses only the visible-evidence rule, never the hidden result. Test in Task 4.
5. **A dev chain missing from the results** (crash). Expected: `not_run` counted in the denominator (already implemented), extended to sample ids. Test in Task 4.
